# Data

Raw and cleaned CSV files are generated by running the pipeline scripts in order:

1. `scripts/01_pull_data.py` — pulls from USAspending.gov API
2. `scripts/02_clean_data.py` — cleans and validates
3. `scripts/04_run_sql_analysis.py` — loads into SQLite and exports results

Data source: [USAspending.gov](https://www.usaspending.gov) public API (DATA Act)
